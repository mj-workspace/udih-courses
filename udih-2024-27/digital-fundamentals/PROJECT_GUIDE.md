# PROJECT_GUIDE.md

## Какво е това

Съдържателно репозитори за **курс „Въведение в дигиталната грамотност"**, предназначен за 25–30 служители на ВиК дружество (без предварителни знания, всякакви роли извън IT). Организиращо тяло: Академия по национална и информационна сигурност. Формат: 15 учебни часа в 2 дни (от тях 9 ч 45 мин преподаване + 2 часа финален изпит).

Репозиторито съдържа:

- Изходни Markdown документи (програма за курса, ръководство за лектора)
- **React уеб приложение** (`lecturer-guide/`) — интерактивен „пищов" за лектора, използван по време на преподаване

## Ключови ограничения (out of scope)

- **Дълбоко в Office (Word/Excel/PowerPoint)** — споменава се само за обща култура в 1.6, тема е на отделен курс
- **Програмиране и скриптове** — никакъв код, команден ред, скриптинг
- **Корпоративна IT администрация** — Active Directory, Group Policy, инфраструктура — не за крайни потребители
- **Дълбока криптография/математика** — само концептуално (как работи Wi-Fi паролата, не RSA mathematics)

Без предварителни знания. Не приемай, че разбират технически термини. Аналогии от ежедневието са по-силни от технически паралели. Английските термини се появяват само където са стандартни (Wi-Fi, email, LinkedIn, AI) — иначе превеждай.

## Lecturer-Guide приложение

### Стартиране

```bash
cd lecturer-guide && pnpm dev
```

### Архитектура

**Стек:** React + Vite + Tailwind. Без router, без state management библиотека.

**Layout:** sidebar ляво + основна зона дясно. Когато модул е активен, неговите подсекции (напр. 1.1, 1.2, …) се показват inline под него в sidebar-а.

**Навигация:** `navigationOrder` — плосък масив от section ID-та в хронологичен ред. Бутоните Предишна/Следваща минават през тях последователно.

**Сплит на М6 и М7:** `module6.js` и `module7.js` експортват по един обект. `index.js` ги разделя на `module6-part1`/`module6-part2` и `module7-part1`/`module7-part2` чрез `.filter()` — един source of truth.

### Data модел

```
CourseModule {
  id: string              // "module1", "intro", "exam"
  title: string
  duration: string        // "50 мин"
  timeMarker: string      // "Ден 1, 09:40 – 10:30"
  note: string            // Бележка за лектора (italic под заглавието)
  sections: Section[]
}

Section {
  id: string              // "1.1", "intro-main", "exam-main"
  title: string
  talkingPoints: TalkingPoint[]
  examples: (string | Example)[]   // Реални случаи, аналогии
  transition?: string              // "ПРЕХОД →" текст
}

TalkingPoint {
  text: string                     // Поддържа **bold** синтаксис
  children?: TalkingPoint[]        // Разгъващи се подточки
  detail?: string                  // Подробно обяснение — отваря DetailPopup при клик
}

Example (нов формат) {
  text: string
  detail?: string
}
```

### Detail Popup система

Talking points с `detail` поле стават кликваеми:

- **Leaf item** (без children): текстът е с пунктирано подчертаване → клик отваря popup
- **Parent item** (с children): ℹ иконка вдясно → клик отваря popup

Popup-ът е модален. Поддържа `**bold**`, `\n\n` за параграфи, `!!текст!!` за **червени** лични бележки към лектора.

## Езикова конвенция

Цялото съдържание е на **български**. Английски термини се появяват само където са стандартни и разпознаваеми за начинаещ потребител: Wi-Fi, email, Zoom, Google Meet, Facebook, Instagram, TikTok, LinkedIn, ChatGPT, Claude, AI. Технически или маргинални английски термини се превеждат на български с английския в скоби при първа поява.

## Ключови решения

- Приложението е **лично за лектора** — не е видимо за курсистите
- **Без автоматизирани тестове** — ръчна верификация
- **Без dark mode, mobile, search** — out of scope
- Поддръжката се прави изцяло от **Claude Code** — редакции на data файлове
